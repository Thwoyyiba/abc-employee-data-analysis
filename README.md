## Project Overview
This project analyzes employee data from ABC company using Python to uncover patterns in team distribution, employee roles, age groups, and salary trends.

##  Preprocessing
- Cleaned the dataset and handled missing values  
- Corrected the height column with realistic random values (150–180 cm)  

## Analysis Performed
- Employee distribution by team  
- Employee distribution by position  
- Age group analysis  
- Salary expenditure by team and position  
- Correlation between age and salary  

## Tools Used
- Python  
- Pandas  
- Matplotlib / Seaborn  
- Jupyter Notebook  

##  Key Insights
- Employee distribution across teams is almost equal, indicating a balanced dataset  
- Majority of employees fall in the 22–30 age group, showing a young workforce  
- Highest salary expenditure is observed in specific roles like SG and PF (or top-performing teams if calculated)  
- Age and salary show a weak positive correlation (~0.21), meaning salary is not strongly dependent on age  

##  Conclusion
The analysis reveals that the dataset is well-balanced across teams, with a workforce dominated by young professionals. While certain positions are more common than others, salary distribution is highly variable and not strongly tied to age. This suggests that compensation is influenced more by role, skill, and performance rather than seniority alone.
